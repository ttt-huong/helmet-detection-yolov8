# Agent team preference

- For project work, use a four-member team: the primary agent plus three subagents, running in parallel when the task allows.
- If the platform exposes fewer than four concurrent slots, use the maximum available and continue the work without waiting for unnecessary clarification.
- Never run model-training jobs or notebook training cells on the local machine; train only in a managed cloud GPU runtime. Local static UI checks and data preparation are allowed.
